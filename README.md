# Quiz Application

An interactive quiz application built using HTML, CSS, and JavaScript. The application allows users to test their knowledge through different difficulty levels and tracks their quiz performance.

## Features

- 20 quiz questions
- Easy, Medium, and Hard difficulty levels
- Multiple-choice questions
- 30-second timer for each question
- Automatic score calculation
- Percentage and grade calculation
- Correct and incorrect answer indication
- Answer review after completing the quiz
- Quiz history tracking
- Best score and average score statistics
- Local Storage for saving quiz history
- Responsive design for different screen sizes

## How to Use

1. Open the Quiz Application.
2. Select a difficulty level.
3. Read each question carefully.
4. Select your answer.
5. Complete all questions within the given time.
6. View your score and grade.
7. Review your answers if needed.
8. Check your previous attempts in Quiz History.
